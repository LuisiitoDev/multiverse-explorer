# Evidencias pendientes

Guarda una carpeta por laboratorio y sesión. Usa las plantillas de `../templates/`. Registra fecha, rol, tarea, commit inspeccionado o probado, comandos, resultados y referencias. No guardes tokens ni datos sensibles. Solo marca PASS cuando exista una validación ejecutada que respalde esa afirmación. NOT_RUN y BLOCKED deben explicar qué falta.
